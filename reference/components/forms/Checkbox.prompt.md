Checkbox with inline label and optional description — used in forms, survey skip-logic options and settings.

```jsx
<Checkbox label="Sync over Wi-Fi only" defaultChecked />
<Checkbox label="Include audio prompts" description="Plays a recording before each item." />
<Checkbox round label="Grade 3" />
```

Props: `label`, `description`, `round`, plus native input attrs (`checked`, `onChange`, `disabled`).
