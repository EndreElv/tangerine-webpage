Surface container for grouped content — product cards, panels, list items.

```jsx
<Card elevation="raised" accentTop>
  <h3>Tangerine®</h3>
  <p>Large-scale assessments and surveys.</p>
</Card>

<Card interactive media="/assets/imagery/reading.jpg">
  <h3>Reading</h3>
</Card>
```

Props: `elevation` (`flat`/`raised`), `interactive` (hover lift), `accentTop` (brand bar), `media` (image URL or node), `padded`.
