Big-number metric for dashboards and impact strips — Tangerine is a data product, so these do heavy lifting.

```jsx
<Stat value="5.1M" label="assessments conducted" gradient size="lg" />
<Stat value="86.4%" label="oral reading fluency" delta="+4.2 pts" trend="up" />
<Stat value="65" label="countries" />
```

Props: `value`, `label`, `delta`, `trend` (`up`/`down`), `size` (`sm`/`md`/`lg`), `gradient`.
