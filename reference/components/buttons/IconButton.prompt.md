Circular icon-only button for toolbars, table rows and compact controls — always supply `label` for accessibility.

```jsx
<IconButton label="Sync now" variant="soft"><span>⟳</span></IconButton>
<IconButton label="More" variant="ghost">⋯</IconButton>
<IconButton label="Add" variant="solid" size="lg">+</IconButton>
```

Variants: `ghost` (default), `soft` (tinted), `solid` (brand). Sizes: `sm` / `md` / `lg`.
